# Overstrum

This GitHub organization contains public source releases of [Overstrum](https://overstrum.com).

It's still a work-in-progress - if you see an empty repo here and there, it's a placeholder that will be published later on.

> [!NOTE]
> These public source releases may exclude or replace some specific files, and may not contain full commit history.
> They should still be buildable, as anything excluded that's needed to build will be instead replaced with a stub.

## Contributions, issues



To report issues:
- Please visit the [Overstrum Discord](https://overstrum.com/discord)'s #triage channel.
- For anything sensitive, like a security issue or generally any issue that should be discussed in private, please use one of the direct contact methods listed in *Contacts*.

To contribute:
- As these repositories are downstream of the internal code repositories Overstrum is built in, pull requests are closed on them.
- Contributing is still welcome - if you'd like to work on something, please feel free to do so and submit patches via the contact methods listed in *Contacts*.
  - If you are planning to contribute anything bigger than just a small change or fix, I'd appreciate it if you can get in touch first via the contact methods listed in *Contacts* so we can discuss before and during!
